# Calculadora de Impuestos de Importación

Proyecto Java/Swing para calcular de forma orientativa las principales contribuciones de una operación de importación.

## Cambios de esta versión
- Barra de desplazamiento **vertical y horizontal** en la calculadora y marco legal.
- El panel **Datos de la operación** tiene su propia barra de desplazamiento (vertical y horizontal), para que los campos, la lista y los botones Limpiar/Calcular no se traslapen ni se corten.
- Pantalla de bienvenida al iniciar.
- Burbujas de ayuda al pasar el cursor sobre los principales conceptos.
- Aviso orientativo cuando se selecciona **Otro**.
- Conserva el catálogo de productos y las operaciones de cálculo.

## Ejecutar
- Con Java 11 o superior: doble clic en `CalculadoraImpuestosImportacion.jar` si Windows tiene asociado Java.
- También puede ejecutarse con `EjecutarCalculadora.bat`.
- El código fuente está en `src/main/java`.

## Nota
Es una aplicación académica. Las fracciones, tasas, NOM, permisos, cuotas compensatorias y demás requisitos deben verificarse con la normativa vigente antes de una operación real.
